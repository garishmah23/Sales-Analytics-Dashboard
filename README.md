# Sales Dashboard using Python, Pandas and Matplotlib

## Project Overview

This project is a simple Sales Dashboard created using Python, Pandas, and Matplotlib. It helps analyze sales data and visualize important business insights such as total sales, profit distribution, and monthly sales trends.

The dashboard reads sales data from a CSV file, processes the information using Pandas, and generates charts using Matplotlib.

## Features

* Load and analyze sales data from CSV file
* Calculate total sales and total profit
* Display sales by product using bar chart
* Show profit distribution using pie chart
* Visualize monthly sales trend using line chart
* Save dashboard as image file
* Store sales analysis report in a text file
